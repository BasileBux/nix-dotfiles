# Fleet

## Identify the current machine

Check the hostname first:

```bash
hostname
```

The nixos config lives on the simon host only. A mirror is available at https://github.com/BasileBux/nix-dotfiles but it might not be up to date. All machines are defined in the NixOS flake at `~/nixos` (hosts in `~/nixos/hosts/`). If `~/nixos` exists, you are almost certainly on **simon**.

## The fleet

All NixOS hosts share the same user setup conventions: SSH on port **2222**, key-only auth (no passwords, no root login), fail2ban, and **nushell as the default shell**. Most are on the Tailnet `tail7925e1.ts.net`.

### simon — laptop / management station (x86_64)

- ASUS Zephyrus (GA402), Ryzen 9 6900HS, 32 GB RAM, Hyprland + asusctl. This is the desktop machine used to manage all other machines.
- **Config lives here**: the flake is at `~/nixos` on simon. Edit host configs there and deploy from simon.
- Tailscale IP `100.79.180.68` (user `basileb`). SSH alias `simon`.
- Roams onto untrusted networks → encrypted DNS (DoT via Quad9, opportunistic).
- Tailscale operator is `basileb` (tailscale CLI without sudo).

### kamina — desktop / VM host (x86_64)

- AMD Ryzen 7 255 (16 threads), 22 GB RAM, stays at home on the LAN.
- **VM host**: libvirtd enabled with a subnet router, so VMs are reachable from the tailnet. `virsh list --all` to see VMs.
- **Wake-on-LAN** enabled (UDP port 9); wheel can `sudo poweroff`/`sudo reboot` without password (used by upsnap for remote wake/shutdown).
- Tailscale IP `100.100.86.25` (user `basileb`). SSH alias `kamina`.

### genome — Raspberry Pi 5 home server (aarch64)

- Cortex-A76, 16 GB RAM, 1 TB NVMe. Always-on, on the home LAN.
- **Runs the services**: vaultwarden, jellyfin (+ seerr), linkwarden (+ meilisearch, postgresql), qbittorrent (+ prowlarr, radarr, sonarr), upsnap, simple-todo. Also the only host with `wheelNeedsPassword = false` (no sudo password).
- **Do NOT touch boot config casually**: firmware-direct kernel boot (no U-Boot), and previously-added `crashkernel`/`ramoops` kernel params hard-hung the boot. See the comments in `~/nixos/hosts/genome/extra-config.nix` before changing anything boot-related. Recovery requires power cycle + editing `cmdline.txt` from the installer.
- Builds against the `nixos-raspberrypi` fork, not nixpkgs.
- Tailscale IP `100.82.254.103` (user `basileb`). SSH alias `genome`.

### yoko — Hetzner cloud VPS (aarch64)

- Public-facing server at `asbel.xyz` (user `eugene`, **not** `basileb`). Not on the tailnet — reach it via its public address.
- Strict fail2ban (`maxretry = 3`, incremental bantime) — don't make repeated failed connections, or you'll lock yourself out.
- IPv6 is configured manually; ~37 GB disk (watch disk usage).

### Others (reachable via SSH aliases but not part of this flake's hosts)

- `buxtorf-synology` — Synology NAS, via tailnet MagicDNS, port 2222.

## Accessing the machines

SSH config aliases are generated by the flake (`~/nixos/modules/ssh.mod.nix`) — use them, they already encode the right host, port and user:

```bash
ssh simon      # only useful from another host; you are probably already on simon
ssh kamina
ssh genome
ssh yoko       # -> eugene@asbel.xyz:2222
ssh buxtorf-synology
```

Mosh is installed on all hosts for flaky/roaming connections. To access hosts **other than simon**, you must be explicitly allowed to (they are managed from simon over the tailnet).

## Running commands on remotes

**The default shell is nushell**, not bash. A remote command string is interpreted by nushell, so naive quoting will fail or behave unexpectedly. To run bash on a remote:

```bash
# Interactive bash session
ssh kamina bash

# One-off command (note: outer quotes for nushell, inner for bash)
ssh genome "bash -c 'df -h /'"

# Multi-line script
ssh yoko "bash -c 'systemctl status nginx; df -h'"
```

Do not pipe bash/POSIX syntax directly into ssh (`ssh host 'cmd1 && cmd2'`) — that is nushell syntax territory and will misbehave.

## Which host to edit config for

Always edit the config for the host you are working on in the flake at `~/nixos` on **simon** (unless explicitly asked to work on another host). Reminder: when SSHing into a host you will land in nushell, not bash.
